Help Desk Bot

A website chatbot that answers customers from a business's own documents, shows where each answer came from, and says “I don't know” instead of making things up.

This demo is set up for Tidewater Fitness, a made-up gym. The AI search model runs entirely in your browser, so nothing you type is sent to a server.

Try it with your own document
Optional: fuller answers with Gemini

By default, answers are quoted straight from the documents. Paste a free Google AI Studio key to have Gemini write the answer instead, still using only the matched sources. The key stays in this tab's memory and is never saved.

How it works: documents are split into sections and turned into embeddings (all-MiniLM-L6-v2 via transformers.js). A question is matched against every section and sentence, the best section is quoted, and anything below a confidence threshold gets an honest “I don't know”. Source code
